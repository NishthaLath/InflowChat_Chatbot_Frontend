# InflowChat Chatbot Frontend

A modern, feature-rich React-based chatbot application powered by OpenAI's API. This application provides a ChatGPT-like conversational interface with support for multiple languages, conversation history, and advanced features.

## Features

- **OpenAI Integration**: Uses OpenAI's [Completion API](https://api.openai.com/v1/chat/completions) for intelligent responses
- **Stream Mode**: Responses are returned in real-time using [stream mode](https://platform.openai.com/docs/api-reference/chat/create#stream) as they are generated by OpenAI
- **ChatGPT-like Experience**: Familiar conversation style for an intuitive user experience
- **Multi-Language Support**: Available in 16+ languages including:
  - Deutsch, Ελληνικά, English, Español, Français, हिन्दी, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Русский, Svenska, ไทย, Tiếng Việt, 中文
- **Model Selection**: Choose from various OpenAI models (gpt-3.5-turbo, gpt-4, etc.)
  - Model context window and knowledge cutoff date are displayed
  - *Note: GPT-4 API access requires at least [one successful payment](https://help.openai.com/en/articles/7102672-how-can-i-access-gpt-4) through the OpenAI platform*
- **Rich Text Formatting**:
  - Markdown formatting support
  - Syntax highlighting for code blocks
- **Conversation History**:
  - Persistent storage using browser's IndexedDB API
  - Organized by time periods (Today, Yesterday, Last Week, Last Month)
  - Search functionality for finding specific conversations
  - Editable conversation titles
- **Error Handling**: Gracefully handles errors including token limit exceeded scenarios
- **System Prompts**: Customize AI behavior with custom instructions
- **Secure Configuration**: API key management through local.env.json

## Prerequisites

- **Node.js**: Version 18.0.0 or higher
- **npm**: Comes with Node.js
- **OpenAI API Key**: Get yours from [OpenAI Platform](https://platform.openai.com/)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/NishthaLath/InflowChat_Chatbot_Frontend.git
   cd InflowChat_Chatbot_Frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure your OpenAI API key:
   - Create a `local.env.json` file in the root directory
   - Add your OpenAI API key to the configuration file

## Available Scripts

### Development

```bash
npm start
```
Builds CSS and starts the development server using Vite. The app will open at [http://localhost:5173](http://localhost:5173) (default Vite port).

### Production Build

```bash
npm run build
```
Builds CSS, compiles TypeScript, and creates an optimized production build using Vite.

### Preview Production Build

```bash
npm run serve
```
Serves the production build locally for testing.

### Build CSS

```bash
npm run build:css
```
Compiles Tailwind CSS styles from `src/index.css` to `src/tailwind.css`.

## Technology Stack

- **Frontend Framework**: React 18.2.0
- **Language**: TypeScript 5.2.2
- **Build Tool**: Vite
- **Styling**: TailwindCSS with PostCSS
- **Routing**: React Router DOM 7.1.1
- **State Management**: React Context API
- **UI Components**:
  - Headless UI
  - Heroicons
  - Radix UI (Tooltips)
  - React Select
- **Markdown & Syntax Highlighting**:
  - React Markdown
  - React Syntax Highlighter
  - Highlight.js
  - GitHub Markdown CSS
- **Database**: Dexie (IndexedDB wrapper)
- **Internationalization**: i18next with React bindings
- **Testing**: Cypress (E2E testing)
- **Notifications**: React Toastify
